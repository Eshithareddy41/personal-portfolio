# Personal Portfolio Website

A modern and responsive portfolio website developed to showcase my projects, technical skills, academic background, and professional interests in software development and computer science.

## Overview

This portfolio highlights my work in frontend development, operating systems, and problem solving. The website is designed with a clean user interface, responsive layout, and smooth user experience across different devices.

## Key Features

- Responsive and mobile-friendly design
- Modern UI with dark/light mode support
- Project showcase with GitHub integration
- Technical skills and achievements section
- Resume integration
- Smooth scrolling navigation
- Optimized layout for better readability and accessibility

## Tech Stack

- CSS3
- JavaScript
